Seven Key Concepts

These terms make it easier to understand how browsers and websites work.

1. Web Browser

An application that retrieves and displays web pages, such as Firefox or Chrome.

2. URL

A web address that identifies where a resource is located online.

3. HTML

The markup language that structures headings, paragraphs, links, and other page content.

4. CSS

The language used to style a webpage, including colors, fonts, and layouts.

5. Rendering Engine

The part of a browser that interprets web content and draws the page on the screen.

6. Cookies

Small pieces of information that websites can ask browsers to store, such as preferences or session details.

7. HTTPS

A secure version of HTTP that encrypts data between a browser and a website.
